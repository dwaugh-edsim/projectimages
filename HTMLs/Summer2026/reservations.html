💡 Logistics & Route Insights

⚠️

Aug 6: Liverpool to Galway Transit

Multi-step transit day (flight Liverpool → Dublin, then bus Dublin → Galway). It is completely doable, but expect it to eat up most of the morning and afternoon.

✈️

Aug 12: Budapest to Kraków Transit

Look into a quick flight if budget allows. The train option is incredibly scenic but usually takes closer to 7–8 hours (or requires an overnight sleeper), rather than 4.

🌿

Olomouc Stopover Advantage

Including Olomouc between Wrocław and Prague breaks up the train travel perfectly and gives you a breather from the massive tourist crowds with an authentic, low-tourist Czech vibe.

August Weather Profile

Lisbon & Budapest: Hot & sunny (~28°C). Pack swimsuits (Budapest Baths!) and light clothing.
Galway & Liverpool: Cooler (~19-20°C) and rain-prone. Pack layers and a waterproof shell jacket.
Central Europe: Warm (~24°C). Great walking weather.

🔌

Power & Tech Needs

UK (Liverpool): Type G plug adapter.
Europe (others): Type C/E/F adapters.
Data: Set up eSIMs (e.g., regional Europe eSIM) before landing to stay connected.

Google Apps Script Setup:
  1. Open a Google Sheet.
  2. Go to Extensions > Apps Script.
  3. Delete any default code and paste this script: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.source,
    data.type,
    data.city,
    data.cost,
    data.currency,
    data.notes,
    data.link
  ]);
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}
  4. Click Deploy > New deployment. Select type Web app.
  5. Set "Execute as" to Me and "Who has access" to Anyone.
  6. Click Deploy, authorize permissions, and copy the Web App URL. Paste it in the input above.
