# Three-Term Assessment Weights — All Three Courses (2026–27)
**Status:** Replaces the two-term ("45/45 around Christmas") structure inherited from the summer planning docs — the real Elem/Middle/Jr year is **three terms: T1 Sept 1–Nov 20 · T2 Nov 23–Mar 5 · T3 Mar 8–Jun 30**, with report cards ~Nov 23–30, ~Mar 15–25, June. This file also fixes the HL9 assessment plan's 7% weight oversubscription (summatives itemized to 69% vs. categories claiming 62%). Underlying docs untouched.

**Principle:** term marks should reflect work completed *in that window*. Term weights are therefore **not equal thirds** — the windows contain ~27% / ~34% / ~39% of the year's classes. Report-card marks per window = (summatives completed in window, scaled) + journals + participation. Per-section dates live in the companion outlines/calendar files.
