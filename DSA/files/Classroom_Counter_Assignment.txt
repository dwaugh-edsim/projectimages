Classroom Counter Design Challenge


Create a Classroom Counter prototype that displays the total number of people in the classroom and if the hall pass is in use.














I Can
	Follow the I can statement listed below to successfully complete this challenge:


* I can code a device to act as a counter for a DSA Classroom


* I can code my counter to display the total number of students in the room for that day and if the hall pass is in use


* I can present my prototype to my peers and DSA staff


* Bonus: I can analyze and evaluate the impact of incorporating  a Makey Makey.
